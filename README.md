# Место на дисках

Небольшое приложение macOS для строки меню. Рядом с иконкой диска показывает ёмкость внутреннего тома и свободное место цифрами без обозначения единиц, например `245/54`. В окне приложения можно выбрать расположение чисел в одну или две строки (ёмкость сверху, свободное место снизу) и настроить размер цифр для каждого варианта. Числа в строке меню выражены в ГБ; подробные значения в окне подписаны единицами измерения. По нажатию открывается окно с ёмкостью тома, занятым и свободным местом для внутреннего и подключённых внешних физических томов. Для APFS ёмкость тома отражает доступное томам хранилище контейнера и может отличаться от полной паспортной ёмкости физического SSD.

## Запуск

Нажмите **Run** в Codex или выполните `./script/build_and_run.sh`. Локальная сборка находится в `dist/DiskSpaceMenu.app`.

Для установки на другой Mac скачайте универсальный ZIP из раздела Releases на GitHub, распакуйте и перенесите приложение в «Программы». Требуется macOS 14 или новее. Сборка не нотарифицирована Apple: при предупреждении о непроверенном разработчике откройте «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть». Для подготовки архива из исходников выполните `./script/package_release.sh`.

Приложение читает только системные сведения о смонтированных томах и их ёмкости. Оно не просматривает файлы. Показания обновляются каждую минуту, при открытии окна, при подключении или отключении тома и по кнопке обновления. Автозапуск выключен, пока пользователь не включит его в окне приложения; macOS может потребовать отдельного разрешения в настройках входа.
