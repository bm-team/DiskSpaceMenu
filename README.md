# Место на дисках

Небольшое приложение macOS для строки меню. Показывает мелкими цифрами ёмкость внутреннего тома и свободное место через косую черту, например `245/54 ГБ`. По нажатию открывается окно с ёмкостью тома, занятым и свободным местом для внутреннего и подключённых внешних физических томов. Для APFS ёмкость тома отражает доступное томам хранилище контейнера и может отличаться от полной паспортной ёмкости физического SSD.

## Запуск

Нажмите **Run** в Codex или выполните `./script/build_and_run.sh`. Локальная сборка находится в `dist/DiskSpaceMenu.app`.

Приложение читает только системные сведения о смонтированных томах и их ёмкости. Оно не просматривает файлы. Показания обновляются каждую минуту, при открытии окна, при подключении или отключении тома и по кнопке обновления. Автозапуск выключен, пока пользователь не включит его в окне приложения; macOS может потребовать отдельного разрешения в настройках входа.
